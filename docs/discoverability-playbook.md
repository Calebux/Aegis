# Aegis Discoverability Playbook

Goal: when builders search for Stellar agents, x402 agents, Soroban policy
agents, MCP Stellar tools, or LLM agent infrastructure, Aegis should be easy to
find and easy for crawlers to summarize correctly.

## Canonical Positioning

Use this exact phrasing consistently:

> Cal-AgentKit is the agent execution and trust infrastructure for Stellar.

Supporting phrase:

> Build governed AI agents on Stellar with wallets, x402 payments, MPP-ready
> discovery, Soroban spend policies, on-chain reputation, verifiable outputs,
> and MCP tools.

## Indexed Assets

- Root `llms.txt` for repository-level LLM context.
- Dashboard `/llms.txt` for deployed app context.
- Dashboard `/sitemap.xml` generated by Next.
- Dashboard `/robots.txt` generated by Next.

- Package README files for npm/GitHub indexing.

## Publish Checklist

- Set `NEXT_PUBLIC_SITE_URL` to the production dashboard URL before deploy.
- Submit the repo and deployed site to search engines.
- Publish `@calebux/agent-kit` with the expanded keywords.
- Publish `calagent-mcp-stellar` with the expanded keywords.
- Link the deployed `/api/agents` and `/llms.txt` from the project README.
- Write one technical post using the title:
  "Building Governed AI Agents on Stellar with x402, Soroban, and MCP".
